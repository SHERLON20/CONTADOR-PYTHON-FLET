🔢 Contador com Python + Flet

Aplicação desktop desenvolvida em Python utilizando o framework <a href="https://flet.dev/">Flet</a>, com foco na criação de interfaces modernas e interativas.

O projeto consiste em um contador simples e intuitivo, permitindo incrementar e decrementar valores através de uma interface gráfica amigável.

O Flet permite criar aplicações desktop, web e mobile utilizando apenas Python, oferecendo uma alternativa moderna para desenvolvimento de interfaces gráficas.

▶️ Como Executar o Projeto
1️⃣ Clone o repositório
git clone https://github.com/SHERLON20/CONTADOR-PYTHON-FLET.git
2️⃣ Acesse a pasta do projeto
cd CONTADOR-PYTHON-FLET
3️⃣ Instale as dependências
pip install flet

O Flet pode ser instalado diretamente via pip.

4️⃣ Execute o projeto
python contador.py

ou

flet run contador.py

O Flet permite executar aplicações desktop e web utilizando o mesmo código Python.
